점령된 자료실

자료는 이제 코드가 아닌 데이터베이스에 있고, 서버 함수를 거쳐 읽습니다. 아래 기록은 모두 실습을 위해 만든 가상 자료입니다.

자료 API는 로그인 토큰을 검사합니다. 로그인하지 않은 방문자에게는 자료를 보내지 않고, 로그인한 사용자에게는 자기 메모만 보냅니다.
지금은 오프라인입니다. 인터넷에 연결되면 자료를 다시 불러와 주세요. 메모는 이 기기에 저장되지 않습니다.

기기 승인 상태

로그인하면 이 기기의 승인 상태를 서버에서 확인합니다.

승인 요청 버튼은 요청만 보냅니다. 상태는 서버가 돌려준 승인 결과로만 표시합니다. 반 엔진이 연결되지 않으면 자료실 서버의 자체 기록을 씁니다.

브라우저에서 실행 중입니다. 앱으로 설치해도 기기 승인이 확인되는 것은 아닙니다.
